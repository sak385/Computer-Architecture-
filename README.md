# Computer Architecture 
This repository contains my programming assignments for Computer Architecture . Each assignment is organized into its own folder, containing the relevant source code.

# Assignments
Hashing  — C program that generates a unique machine token by reading the system's machine ID, combining it with a course-specific salt, and hashing the result using the DJB2 algorithm for environment verification.

Coding Project 1 — C program that calculates the absolute difference between two numbers using a custom function and prints the result to the console.

Cache Predictor — The code uses C programming to process hexadecimal memory addresses from input files and write modified addresses to output files. The initial version preserves the addresses, while the updated version adds 4 to each address.

# Languages and Tools
C, PowerShell, VS Code, Rutgers iLabs

# Repository Structure
Each assignment has its own folder to keep the source code organized and separate.
